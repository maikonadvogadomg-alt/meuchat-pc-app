# 💬 Meu Chat para PC (.exe)

O mesmo Meu Chat do celular, numa **janela própria do Windows**, com a **🧰 mesa do lado** já aberta:
- **▶ Playground**: o código que a IA fez vai para lá (botão ➡ Mesa nos blocos de código). Mexa e veja funcionando.
- **🔗 Links**: os seus links guardados, abrindo ali do lado (o colador de links dentro do chat).
- **🧪 Códigos**: os códigos guardados (💾).
A mesa **não gasta nada da IA**: só vai para a IA o que você mandar de volta (↩ Mandar para o chat).

Também vem: a **🗣 voz Francisco grátis** (sem Python) e o **🦙 Ollama** liberado sozinho.
Usa a porta **7730** (abre junto com o Mini SK 7680 e o Laboratório 7690).

## Como gerar o .exe (igual ao Mini SK e ao Laboratório)
1. No Mini SK: abra este zip como projeto → 🐙 GitHub → criar repositório (**privado**) → enviar.
2. No GitHub: **Actions** → "Programa .exe para Windows" → **Run workflow**.
3. Quando ficar verde: **Releases** → baixe **MeuChat-Instalar.exe** (ou o "sem-instalar").

## Os seus dados
Ficam no próprio PC (como no navegador). Para levar do celular para o PC: no celular ⚙️ → 💾 Backup → no PC ⚙️ → Restaurar.
Com o login do Supabase ligado, aparecem sozinhos.
